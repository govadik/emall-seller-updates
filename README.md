# Емолл Продавец — приложение Emall для Android

**Емолл Продавец (Emall Seller)** — независимое Android-приложение для продавцов маркетплейса Emall. Оно помогает смотреть товары, цены и остатки, работать с заказами и отправлениями, пользоваться аналитикой и получать уведомления.

- [О приложении и его функциях](https://govadik.github.io/emall-seller/)
- [Канал приложения в Telegram](https://t.me/emallseller_app)
- [Скачать последнюю опубликованную версию](https://github.com/govadik/emall-seller-updates/releases/latest)
- [История версий](https://github.com/govadik/emall-seller-updates/releases)

## Возможности

- Просмотр каталога товаров, изображений, категорий, цен, скидок и остатков.
- Просмотр заказов, выкупов и статусов отправлений.
- Аналитика продаж за выбранный период.
- Фоновые уведомления о новых заказах и низких остатках.
- Печать адресных и термоэтикеток, QR-кодов.
- Демо-режим для просмотра данных; изменение товаров и печать доступны с активной лицензией.

Для подключения магазина используется API-ключ продавца Emall. Приложение сохраняет ключ на устройстве в защищённом виде.

## Установка и обновление

1. Скачайте APK из [последнего релиза](https://github.com/govadik/emall-seller-updates/releases/latest) и установите его на Android.
2. Приложение проверяет опубликованные обновления при запуске и в фоне, затем скачивает доступный APK.
3. Когда обновление готово, нажмите уведомление или откройте в приложении раздел «Ещё» → «Установить обновление».
4. Подтвердите установку в системном окне Android. При первом обновлении Android может попросить разрешить установку приложений из этого источника.

APK публикуются в GitHub Releases. При загрузке обновления приложение сверяет SHA-256 файла с опубликованным манифестом. Android всё равно показывает системное подтверждение установки.
