# Емолл Продавец — обновления

Официальное приложение для продавцов Emall. Здесь публикуются APK и информация о версиях.

## Установка и обновление

- Первый APK нужно установить вручную из раздела [Releases](https://github.com/govadik/emall-seller-updates/releases).
- В приложении откройте «Ещё» → «Проверить обновление».
- Приложение скачивает APK и проверяет его SHA-256 перед установкой.
- Для установки Android попросит подтвердить действие. Подключение магазина и настройки сохраняются, если APK подписан тем же сертификатом.

## Для владельца приложения

Для каждой новой версии создайте GitHub Release и прикрепите два файла:

1. `Emoll-Prodavets-<версия>.apk`
2. `update.json` с `versionCode`, `versionName`, прямой ссылкой на APK, SHA-256 и примечаниями.

Версия должна иметь больший `versionCode`, чем предыдущая. Не публикуйте API-ключи, ключ лицензирования или keystore.
