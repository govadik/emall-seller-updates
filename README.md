# Емолл Продавец — обновления

Официальное приложение для продавцов Emall. Здесь публикуются APK и информация о версиях.

## Установка и обновление

- Скачайте APK из раздела [Releases](https://github.com/govadik/emall-seller-updates/releases) и подтвердите установку в Android.
- В приложении откройте «Ещё» → «Проверить обновление». Если версия доступна, приложение откроет страницу релиза GitHub.
- Скачайте APK новой версии со страницы и запустите файл. Android покажет системное подтверждение установки.
- Начиная с версии 0.7.6 APK подписываются постоянным ключом. Для перехода с предыдущих тестовых версий один раз потребуется удалить старую версию и установить новую; после перехода версии с той же подписью ставятся поверх с сохранением данных.
